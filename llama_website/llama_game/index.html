Arcade economy

Every match requires one entry ticket. Skins are cosmetic only. The configured settlement hook routes 100% of each purchase to the 10% Game Rewards Vault.

Live purchases are disabled until an audited vault settlement hook is installed.

Server-authoritative

Start with three lives and a 10-second shield. Reach Level 6 to unlock up to two Heart Matrix upgrades; orb rewards restore lives only to the server-authoritative match cap.

Guarded transactions

Swaps and game purchases require verified public configuration, a user click, final wallet approval, and the audited vault settlement hook.
